Sudoku Game




Features
Gameplay Features

    🎮 Multiple Difficulty Levels: 20 pre-configured puzzles across 4 difficulty tiers

    🕒 Game Timer: Tracks your solving time

    ❌ Mistake Counter: Shows mistakes made vs. maximum allowed

    💡 Hint System: 8 hints per game (reveals correct number)

    ✏️ Note Mode: Track candidate numbers for empty cells

    🗑️ Delete Function: Clear numbers with button or keyboard (Backspace/Delete)

    🔄 Puzzle Navigation: Move between different puzzles

Visual Features

    🎨 Theme Support: Light and dark mode (toggle with 'T' key)

    🔴 Error Highlighting: Wrong numbers stay highlighted in red

    💙 Cell Highlighting: Selected cell, same numbers, and related cells highlighted

    📝 Candidate Numbers: Shows possible numbers in note mode

Technical Features

    📊 Progress Tracking: Saves game progress between sessions

    📈 Game Statistics: Logs completion time, mistakes, and hints used

    🧠 Smart Puzzle Generation: Uses K-means clustering for balanced difficulty

    🖱️ Full Mouse Support: All controls accessible via mouse

How to Play
Basic Controls

    Mouse Click: Select a cell

    Number Keys (1-9): Enter a number in selected cell

    N Key: Toggle note mode

    Backspace/Delete: Clear selected cell

    Escape: Return to menu

    T Key: Toggle light/dark theme

Game Interface

    Top Panel:

        Current time elapsed

        Mistakes counter (X/max)

        Current puzzle number

        Difficulty level

        Note mode status

        Hints remaining

    Right Panel Buttons:

        Hint: Reveal a correct number (8 per game max)

        Delete: Clear selected cell

        Menu: Return to main menu

        Next: Jump to next puzzle

        Notes: Toggle note mode

Game Rules

    Fill the 9×9 grid with digits so that:

        Each row contains all digits from 1-9

        Each column contains all digits from 1-9

        Each 3×3 subgrid contains all digits from 1-9

    Gray cells are pre-filled and cannot be changed

    Red numbers indicate incorrect entries

    The game ends when:

        You complete the puzzle (win)

        You make too many mistakes (loss)

Difficulty Levels

    Super Easy: 45-41 clues (5 puzzles)

    Beginner: 40-36 clues (5 puzzles)

    Intermediate: 35-28 clues (5 puzzles)

    Advanced: 26-18 clues (5 puzzles)
